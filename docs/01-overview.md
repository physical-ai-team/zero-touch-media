# 1. 개요

**실시간 얼굴 인식 기반 스마트 유튜브 미디어 제어 — "화면을 보는 순간 재생되고, 시선을 떼는 순간 멈춘다."**

| 상태 | 결과 |
|---|---|
| Face Detected (인식 완료) | 영상 자동 재생 |
| Face Not Detected (이탈/부재) | 영상 자동 일시정지 (직전 위치 보존) |

- 인식 모델은 ESP32-S3 **보드 안에서** 돈다(Edge Impulse FOMO). 수업 요구사항.
- 판정은 "얼굴이 있는지"만 본다. 시선 방향 추적, 여러 사람 구분, 클라우드는 범위 밖.
- 실패로 보는 것: 재생/정지가 깜빡이듯 반복됨, 장치가 끊겼는데 계속 재생됨.
