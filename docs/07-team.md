# 7. 팀 규칙

| 담당 | 폴더 | 할 일 |
|---|---|---|
| 팀원1 박민성 | `model/` | Edge Impulse 학습·최적화, 정확도·크기·속도 기록, 공개 모델과 비교표 |
| 팀원2 김세광 (팀장) | `firmware/` | 보드·카메라, 모델 이식, MQTT 발행 |
| 팀원3 김정윤 | `broker/`, `server/`, `web/`, `tools/`, 루트 설정 | 브로커, 판정 서버, 유튜브 페이지, 통합, 지연·오판정 측정, 시연 |
| 팀원4 조아람 | `model/testing/` | 시연 장소 데이터 수집(캡처), 실제 보드 정확도 측정(감지율·오탐률), 버전별 비교 |
| 공동 | `docs/`, `HANDOFF.md` | 자기 담당 문서·절만 고친다 |

- 자기 폴더만 고친다. 다른 폴더를 고쳐야 하면 담당자에게 말하거나 이슈를 연다.
- 브랜치: `feat/<담당>-<내용>` (예: `feat/firmware-ei-model`). `main` 직접 push 금지, PR로 병합.
- 규격 변경은 `docs/03-protocol.md`와 `protocol.py`를 같이 고치는 PR로, 세 명 합의.
- PR 병합: 다른 한 명이 확인한 뒤 병합.
- 비밀값(Wi-Fi 비번, Edge Impulse API 키)은 커밋하지 않는다.
