# 6. 일정과 동시 작업

경계마다 **약속(규격)** 과 **가짜 상대**를 둬서 셋이 처음부터 동시에 일한다.

| 경계 | 약속 | 기다리는 대신 쓰는 것 |
|---|---|---|
| 모델 → 펌웨어 | Edge Impulse Arduino 라이브러리(`run_classifier`) | 공개 프로젝트를 그대로 배포한 zip. 나중에 zip만 교체 |
| 펌웨어 → 서버 | MQTT 토픽·JSON (03-protocol.md) | 서버·웹: `tools/fake_esp32.py` / 펌웨어: `mosquitto_sub` |
| 서버 → 웹 | WebSocket `state`/`detect` | 진짜 서버 + 가짜 ESP32 |

| 단계 | 팀원1 박민성 (모델) | 팀원2 (펌웨어) | 팀원3 (브로커·서버·웹) |
|---|---|---|---|
| 0 | 뼈대 공개 ✅ | 저장소 받기, 환경 설치, 03-protocol 읽기 | ← |
| 1 | Edge Impulse 복제 → 학습 | 공개 모델 zip으로 카메라+추론 → MQTT | 방화벽, 판정값 다듬기, 유튜브 페이지 (가짜 ESP32로) |
| 2 | 최적화, 정확도·크기·속도 기록 | 추론 속도·기준값 조정 | 측정(지연, 오판정) |
| 합치기 1 | ← | 진짜 보드 → 서버 → 웹 | 통합 확인, 시연 준비 |
| 합치기 2 | 우리 모델 zip 전달, 비교표 | 모델 교체 | 공개 모델 vs 우리 모델 실측 |
